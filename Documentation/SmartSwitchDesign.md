# 本机负载与智能切换设计

## 目标

应用在同一个面板显示本机 CPU 功率、CPU 温度和风扇转速，并允许这些指标自动驱动散热器的文档、娱乐、专家三档官方配置。自动控制开启时，所有可能与策略冲突的手动切档、待机和固定输出入口都会锁定。

## 数据来源

- CPU 功率：Intel Mac 优先读取 AppleSMC 的 `PCPT` CPU 封装总功率键；Apple Silicon 可使用 HID 电流与电压传感器组合值，缺失时回退到 SMC。
- 整机功率：额外显示 AppleSMC 的 `PSTR`/`PDTR`，用于和 iStat 等工具的“总功率”读数直接核对；它不参与 CPU 功率阈值判断。
- CPU 温度：优先读取系统 HID 温度传感器，Intel Mac 回退到 AppleSMC CPU 温度键。
- 本机风扇：读取 AppleSMC 的 `F0Ac`、`F1Ac` 等实时转速并计算平均值。
- 采样周期为 2 秒，界面和策略使用最近 6 秒内至多 3 个样本的平均值，抑制编译、进程唤醒等瞬时峰值。

单项传感器不可用时，该项不参与判断；只有三项均不可用时才暂停智能判断。

## 状态机

三档按文档、娱乐、专家从低到高排列。每个指标有娱乐和专家两条阈值：

- 升档：任一可用指标达到目标档阈值即升档。
- 降档：所有可用指标都低于较低档阈值后才降档。
- 回差：功率 2 W、温度 3℃、风扇 250 RPM，避免数值在边界附近来回切换。
- 最短驻留：升档立即执行；降档前至少保持当前档位 20 秒，避免防抖策略拖延高负载时的散热响应。

默认阈值针对这台 Intel MacBook Pro 的 CPU 封装功率和实测负载设置：CPU 功率 20/35 W、CPU 温度 60/75℃、风扇 2500/4000 RPM。用户可在智能切换开启后直接拖动两组滑块调整。

## 控制边界

智能模式只选择三档官方配置，不直接发送高强度固定水泵或风扇值。切换后仍由设备自己的温差或功率曲线调度硬件。关闭智能切换后，当前档位保持不变，并重新开放手动控制。
